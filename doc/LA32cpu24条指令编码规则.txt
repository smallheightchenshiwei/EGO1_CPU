LoongArch LA32 课程设计指令编码规范（24条候选子集）
依据：龙芯《龙架构32位精简版参考手册》V1.04，2025年2月
官方手册： https://www.loongson.cn/uploads/images/2025032109211238668.%E9%BE%99%E6%9E%B6%E6%9E%8432%E4%BD%8D%E7%B2%BE%E7%AE%80%E7%89%88%E5%8F%82%E8%80%83%E6%89%8B%E5%86%8C_r1p04.pdf

说明
1. 本文件整理项目计划实现的24条LA32指令，不代表完整实现LoongArch指令集。
2. 所有指令为32位定长指令。以下 opcode 是指令高位的固定编码字段，不是完整32位机器码；寄存器和立即数字段由具体指令操作数填入。
3. 位编号从inst[31]到inst[0]。寄存器编号字段宽度均为5位。
4. 机器码字段布局和执行语义以官方手册附录B及第2.2节为准。
5. 本文件用于项目设计；正式编写译码器前，建议A、B共同再用官方手册核对一次本文档中的字段表，特别是分支偏移拼接和特殊格式。

一、通用指令字段格式

3R格式：
inst[31:15] = 17位opcode
inst[14:10] = rk
inst[9:5]   = rj
inst[4:0]   = rd

2RI12格式：
inst[31:22] = 10位opcode（部分指令实际固定字段宽度可能不同，按下方逐条定义）
对于常规2RI12指令：
inst[31:22] = opcode（10位）
inst[21:10] = 12位立即数
inst[9:5]   = rj
inst[4:0]   = rd

注意：LoongArch不同指令的opcode字段长度并不统一。不要把所有立即数指令都强行套用相同的opcode位宽。下方每条指令均给出其准确的字段边界。

二、A负责主导的12条指令

1. ADD.W
汇编格式：ADD.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000100000
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj + rk，结果取32位；溢出不作特殊处理。

2. SUB.W
汇编格式：SUB.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000100001
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj - rk，结果取32位；溢出不作特殊处理。

3. ADDI.W
汇编格式：ADDI.W rd, rj, si12
格式：2RI12
固定opcode：inst[31:22] = 0000001010（10位）
字段：inst[21:10]=si12，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj + SignExtend(si12, 32)。

4. LU12I.W
汇编格式：LU12I.W rd, si20
格式：1RI20（该指令的具体布局）
固定opcode：inst[31:25] = 0001010
字段：inst[24:5]=si20，inst[4:0]=rd
功能：rd = {si20, 12'b0}。

5. SLT
汇编格式：SLT rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000100010
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：将rj和rk作为有符号数比较；若rj < rk，则rd=1，否则rd=0。

6. AND
汇编格式：AND rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000101001
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj AND rk。

7. OR
汇编格式：OR rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000101010
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj OR rk。

8. XOR
汇编格式：XOR rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000101011
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj XOR rk。

9. ANDI
汇编格式：ANDI rd, rj, ui12
格式：2RI12
固定opcode：inst[31:22] = 0000001101（10位）
字段：inst[21:10]=ui12，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj AND ZeroExtend(ui12, 32)。

10. ORI
汇编格式：ORI rd, rj, ui12
格式：2RI12
固定opcode：inst[31:22] = 0000001110（10位）
字段：inst[21:10]=ui12，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj OR ZeroExtend(ui12, 32)。

11. LD.W
汇编格式：LD.W rd, rj, si12
格式：2RI12
固定opcode：inst[31:22] = 0010100100（10位）
字段：inst[21:10]=si12，inst[9:5]=rj，inst[4:0]=rd
功能：有效地址 = rj + SignExtend(si12,32)；从该地址读取32位字写入rd。

12. ST.W
汇编格式：ST.W rd, rj, si12
格式：2RI12
固定opcode：inst[31:22] = 0010100110
字段：inst[21:10]=si12，inst[9:5]=rj，inst[4:0]=rd
功能：有效地址 = rj + SignExtend(si12,32)；将rd的32位数据写入该地址。
说明：ST.W的第一个汇编操作数rd是待写入内存的数据寄存器，不是目的寄存器。

三、B负责主导的12条指令

13. SLL.W
汇编格式：SLL.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000101110
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj逻辑左移(rk[4:0])位。

14. SRL.W
汇编格式：SRL.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000101111
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rd = rj逻辑右移(rk[4:0])位。

15. SRA.W
汇编格式：SRA.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000110000
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：将rj视为有符号数，算术右移(rk[4:0])位，结果写入rd。

16. SLLI.W
汇编格式：SLLI.W rd, rj, ui5
格式：移位立即数格式
固定opcode：inst[31:21] = 00000010001
字段：inst[14:10]=ui5，inst[9:5]=rj，inst[4:0]=rd
保留字段：inst[20:15]按官方编码固定为0
功能：rd = rj逻辑左移ui5位。
说明：移位量是5位无符号立即数。

17. MUL.W
汇编格式：MUL.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000111100
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：rj与rk相乘，乘积低32位写入rd。

18. DIV.W
汇编格式：DIV.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000000111111
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：将rj、rk视为有符号32位整数相除，商写入rd。

19. MOD.W
汇编格式：MOD.W rd, rj, rk
格式：3R
固定opcode：inst[31:15] = 00000000001000000
字段：inst[14:10]=rk，inst[9:5]=rj，inst[4:0]=rd
功能：将rj、rk视为有符号32位整数相除，余数写入rd。

20. BEQ
汇编格式：BEQ rj, rd, offs16
格式：2RI16
固定opcode：inst[31:26] = 010110
字段：inst[25:10]=offs16，inst[9:5]=rj，inst[4:0]=rd
功能：若GR[rj]等于GR[rd]，则PC = PC + SignExtend({offs16, 2'b0},32)；否则顺序执行。

21. BNE
汇编格式：BNE rj, rd, offs16
格式：2RI16
固定opcode：inst[31:26] = 010111
字段：inst[25:10]=offs16，inst[9:5]=rj，inst[4:0]=rd
功能：若GR[rj]不等于GR[rd]，则PC = PC + SignExtend({offs16, 2'b0},32)。

22. BLT
汇编格式：BLT rj, rd, offs16
格式：2RI16
固定opcode：inst[31:26] = 011000
字段：inst[25:10]=offs16，inst[9:5]=rj，inst[4:0]=rd
功能：若有符号(GR[rj])小于有符号(GR[rd])，则PC = PC + SignExtend({offs16, 2'b0},32)。

23. B
汇编格式：B offs26
格式：I26
固定opcode：inst[31:26] = 010100
字段：inst[25:10]=offs26[15:0]，inst[9:0]=offs26[25:16]
功能：PC = PC + SignExtend({offs26, 2'b0},32)。

24. BL
汇编格式：BL offs26
格式：I26
固定opcode：inst[31:26] = 010101
字段：inst[25:10]=offs26[15:0]，inst[9:0]=offs26[25:16]
功能：r1 = PC + 4；PC = PC + SignExtend({offs26, 2'b0},32)。
说明：BL使用r1作为链接寄存器。

四、实现时必须注意的规则

1. 汇编操作数顺序通常是目的寄存器在前，但分支指令和存储指令有各自的操作数语义，不能一律把第一个寄存器字段当作写回目的寄存器。
2. ADD.W、SUB.W、SLT、AND、OR、XOR、SLL.W、SRL.W、SRA.W、MUL.W、DIV.W、MOD.W均使用rd、rj、rk字段。
3. ADDI.W、ANDI、ORI、LD.W、ST.W的立即数为12位；ADDI.W、LD.W、ST.W使用符号扩展，ANDI、ORI使用零扩展。
4. LU12I.W的si20放在结果高20位，低12位补0。
5. SLLI.W的移位量ui5是5位无符号立即数。
6. BEQ、BNE、BLT的offs16需要拼接低2位00后再符号扩展，分支目标相对当前指令PC计算。
7. B、BL的offs26按指令编码拆分存放，重组后拼接低2位00，再符号扩展；目标地址相对当前指令PC计算。
8. r0恒为0。BL的链接地址写入r1。寄存器堆硬件不应因此限制r1的其他通用寄存器读写用途。
9. LA32通用寄存器宽度为32位。ADD.W和SUB.W结果取低32位，不需要再扩展到更宽寄存器。
10. 本项目暂不实现异常、中断、特权指令等完整架构功能时，应在项目报告中明确说明实现范围。

五、原24条清单需要修正的名称

本项目使用的是SLLI.W，不是SLLI.W之外的自定义移位立即数命名。
LoongArch LA32的指令名是ADDI.W，不是ADDIW。
分支指令BEQ、BNE、BLT的汇编参数顺序为rj、rd、offs16。
ST.W的汇编参数顺序为rd、rj、si12，其中rd提供写入内存的数据。
